# ZaPlani site

The landing page (`index.html`), plain static files. They are published as they are to the
public repo whenClick/zaplani-site (GitHub Pages): https://zaplani.com/ (`CNAME` names the domain).
The web app is at https://app.zaplani.com/, from the public repo whenClick/zaplani-app.

Everything in this folder is published, so keep private tools out of it.

The «Скачать для Android» button links to the latest release of zaplani-site
(`releases/latest/download/zaplani.apk`), published by the Android APK workflow in
whenClick/ZaPlani when its signing and site secrets are set; the button stays hidden until then.
